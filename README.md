# Customer Churn Prediction

Predicting customer churn using business metrics, user engagement patterns, and machine learning models.

## Project Structure
- [`data_analysis.ipynb`](data_analysis.ipynb): Primary Jupyter notebook containing exploratory data analysis, data cleaning, and modeling experiments.
- [`ML_WORKFLOW.md`](ML_WORKFLOW.md): Step-by-step documentation detailing the 6 stages of the machine learning lifecycle for this project.

## Quick Start
1. Activate virtual environment:
   ```bash
   source .venv/bin/activate
   ```
2. Launch Jupyter / open [`data_analysis.ipynb`](data_analysis.ipynb) in your IDE.
